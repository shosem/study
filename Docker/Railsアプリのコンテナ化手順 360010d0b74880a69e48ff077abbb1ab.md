# Railsアプリのコンテナ化手順

## Dockerfileの作成

```docker
# ruby:3.2.5のイメージをベースに
FROM ruby:3.2.5 

# ENVで変数を定義
ENV APP=/app
ENV LANG=C.UTF-8
ENV TZ=Asia/Tokyo

# Node.jsリポジトリを登録＋ビルドツール＋MariaDBクライアント導入 ※１
RUN curl -fsSL https://deb.nodesource.com/setup_lts.x | bash - \
 && apt update -qq \
 && apt install -y build-essential mariadb-client nodejs \
 && npm install --global yarn
 
WORKDIR $APP

# Gemfileをコピーしてキャッシュ用に
COPY Gemfile $APP/Gemfile
COPY Gemfile.lock $APP/Gemfile.lock
RUN bundle install
```

### curlとは

fetchのイメージ。URLを使ってコマンドラインからデータを送受信

### -fsSLとは

オプションの`f`,`s`,`S`,`L`をまとめて書いている。

- `-f`：失敗時にエラーを出す
- `-s`：進捗を表示しない
- `-S`：エラーのみ表示
- `-L`：リダイレクトを有効にする

### RUNでやってること

curl https://…：node.jsをインストールするためのリポジトリをlinuxに登録

apt update -qq：リポジトリ一覧を更新（qq：メッセージなど出力を最小限に）

apt install：ビルドツール、mariaDB、nodejs（更新したヤツ！）のインストール

npm install —global yarn：node.jsをインストールしてnpmが使えるようになり、npmを使ってyarnをインストール

## compose.ymlの作成（db、web、redis）

```docker
services:
  db:
    # 公式のmysqlイメージを使用
    image: mysql:8.0
    # 変数定義
    enviroment:
      MYSQL_ROOT_PASSWORD: password
      TZ: Asia/Tokyo
    ports:
      - '3306:3306'
    # mysql_dataをマウント
    volumes:
      - mysql_data:/var/lib/mysql
    
  redis:
    image: redis:latest # latestは最新版
    command: redis-server
    ports:
      - '6379:6379'
    volumes:
      - redis:/var/lib/redis
      
  web:
    build: .
    command: >
      bash -c "
        bundle install &&
        bundle exec rails db:prepare &&
        rm -f tmp/pids/server.pid &&
        yarn install &&
        ./bin/dev
      "
    tty: true
    stdin_open: true
    ports:
      - '3000:3000'
    volumes:
      - .:/app
      - bundle_data:/usr/local/bundle:cached
      - node_modules:/app/node_modules
    depends_on:
      - db
      - redis

volumes:
  mysql_data:
  bundle_data:
  node_modules:
  redis:
```

### image

公式が用意したimageを使用する。

### volumes

マウントする（繋げる）。`.:/app`では、カレントディレクトリをコンテナの`/app`に繋げる。
作業すると、コンテナの`/app`内も更新されるイメージ。
ホスト ↔️ コンテナ
上位の`volumes`で、使うvolumesを立ち上げる（定義する）。

## database.ymlの修正

```docker
default: &default
  adapter: mysql2
  encoding: utf8mb4
  pool: <%= ENV.fetch("RAILS_MAX_THREADS") { 5 } %>
  username: root
  password: <%= ENV.fetch("MYSQL_ROOT_PASSWORD") { "password" } %> #　これ！
  host: <%= ENV.fetch("DB_HOST") { "db" } %>

development:
  <<: *default
  database: myapp_development
```

## Procfileの作成

```docker
web: env RUBY_DEBUG_OPEN=true bin/rails server -b 0.0.0.0 -p 3000
js: yarn build --watch
```

### webの内容

RUBY_DEBUG_OPEN=true：RUBYデバッガーを有効に
-b 0.0.0.0：すべてのipアドレスからアクセスを許可。docker環境に必要。
-p 3000：ポート3000で起動

### jsの内容

yarn build —watch：ファイル変更を監視してビルド

`./bin/dev` 実行時にこの Procfile.dev を参照し、Rails サーバーと JS ビルドが同時起動される。
